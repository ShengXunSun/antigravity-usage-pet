# Whale Usage Pet (`whale-pet`)

An interactive side-panel pet plugin for Antigravity inspired by `DeepSeek-Balance-Whale-Widget`.

## Features
- **Live Token Tracking**: Automatically tracks `Last Reply`, `This Chat`, `Last 5h`, and `This Week` token usage (`input` + `cache` + `output`) from Antigravity's local conversation transcripts.
- **Quick-Sync Quota Sliders**: Track your remaining plan usage (`%`) for Gemini Weekly, Claude Weekly & 5h, and GPT Weekly & 5h.
- **Interactive Whale Pet**: Bouncy idle & reaction animations, speech bubbles, and click-to-toggle stats dashboard in the Auxiliary Side Pane.
